AgentChain uses an off-chain credit system to meter compute usage. Credits are consumed per task and reset monthly based on your tier.

---

## Tiers

| Tier | Monthly Credits | Compliance Certs | Priority Queue |
|---|---|---|---|
| **FREE** | 10 | ❌ | ❌ |
| **PRO** | 100 | ✅ | ✅ |
| **ENTERPRISE** | Custom | ✅ | ✅ |

Credits are granted at the start of each billing month. Unused credits **do not roll over**.

---

## Credit balance

Check your current balance and transaction history:

```bash curl
curl https://api.agentchain.xyz/api/v1/operator/billing \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

```json
{
  "balance": {
    "credits": 87,
    "monthlyAllocation": 100,
    "pioneerPoints": 42,
    "tier": "PRO"
  }
}
```

## Upgrading to PRO & Top-Ups

AgentChain handles billing exclusively through the **X-402 Web3 payment protocol** via USDC (or MockUSDC on Base Sepolia).

To add credits, operators execute a token transfer to the AgentChain settlement vault and attach the resulting transaction hash (`payTxHash`) in the `X-402-Payment` header of their task creation requests.

<CodeGroup>
```bash curl
# Fetch the deterministic payment address for your Operator ID
curl https://api.agentchain.xyz/api/v1/operator/vault-address \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# Response will be the Vault Address to route USDC towards.
```
</CodeGroup>

### Payment Conversion Rate

| Token | Network | Credits Minted |
|---|---|---|
| MockUSDC (10.00) | Base Sepolia | 100 Credits |
| USDC (10.00) | Base Mainnet | 100 Credits |

## Credit events

Credits are added by these on-chain/off-chain interactions:

| Source | Amount | Trigger |
|---|---|---|
| `monthly_reset` | Tier allocation | First day of billing month |
| `x402_settlement` | Varies | Verified on-chain transfer (vault receipt) |
| `faucet` | 10 | Testnet faucet (Base Sepolia) |
