AgentChain routes AI tasks through a verifiable compute network on Base Sepolia. Every task produces a cryptographic proof anchored to IPFS and attested on-chain via EAS.

This quickstart uses the **REST API directly** — no SDK required.

---

## Step 2 — Fund Your Wallet

Call the faucet to mint MockUSDC to your wallet and pre-fund the payment gate. You need both funded before submitting a task.

<CodeGroup>
```bash curl
curl -X POST https://api.agentchain.xyz/api/v1/faucet/usdc \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"wallet": "0xYOUR_WALLET_ADDRESS", "amount": 10}'
```

```typescript TypeScript
const res = await fetch('https://api.agentchain.xyz/api/v1/faucet/usdc', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.AGENTCHAIN_API_KEY!,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ wallet: '0xYOUR_WALLET_ADDRESS', amount: 10 }),
});

const { paymentAddressTxHash, devWalletTxHash, creditsAdded } = await res.json();
```

```python Python
import requests

resp = requests.post(
  'https://api.agentchain.xyz/api/v1/faucet/usdc',
  headers={'x-api-key': 'YOUR_API_KEY'},
  json={'wallet': '0xYOUR_WALLET_ADDRESS', 'amount': 10},
)
data = resp.json()
payment_tx_hash = data['paymentAddressTxHash']
```
</CodeGroup>

The response includes two tx hashes:

| Field | What it is |
|---|---|
| `devWalletTxHash` | MockUSDC minted to your wallet |
| `paymentAddressTxHash` | MockUSDC minted to the payment gate on your behalf |
| `creditsAdded` | Off-chain credits loaded (10) |
| `instructions` | Pre-built `X-402-Payment` header value — copy this |

<Warning>
**Rate limit:** 1 faucet call per wallet per 24 hours (100 USDC max). The `cooldownUntil` field tells you when you can call again.
</Warning>

## Step 3 — Submit a Compute Task

Pass the `paymentAddressTxHash` from Step 2 as the `X-402-Payment` header (Base64-encoded JSON). The faucet response includes a pre-built header value in `instructions` — copy it directly.

<CodeGroup>
```bash curl
# Build the payment header
PAYMENT_HEADER=$(echo -n '{
  "txHash": "0xYOUR_PAYMENT_TX_HASH",
  "payer": "0xYOUR_WALLET_ADDRESS",
  "amount": "10000000",
  "chainId": 84532
}' | base64)

curl -X POST https://api.agentchain.xyz/api/v1/tasks/submit \
  -H "x-api-key: YOUR_API_KEY" \
  -H "X-402-Payment: $PAYMENT_HEADER" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Summarize the state of the AI agent economy in 3 sentences.",
    "model": "gemma3:4b"
  }'
```

```typescript TypeScript
const paymentHeader = Buffer.from(JSON.stringify({
  txHash: paymentAddressTxHash,   // from Step 2
  payer: '0xYOUR_WALLET_ADDRESS',
  amount: '10000000',             // 10 USDC (6 decimals)
  chainId: 84532,
})).toString('base64');

const task = await fetch('https://api.agentchain.xyz/api/v1/tasks/submit', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.AGENTCHAIN_API_KEY!,
    'X-402-Payment': paymentHeader,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    prompt: 'Summarize the state of the AI agent economy in 3 sentences.',
    model: 'gemma3:4b',
  }),
});

const { taskId, status } = await task.json();
```

```python Python
import base64, json, requests

payment_header = base64.b64encode(json.dumps({
  'txHash': payment_tx_hash,
  'payer': '0xYOUR_WALLET_ADDRESS',
  'amount': '10000000',
  'chainId': 84532,
}).encode()).decode()

resp = requests.post(
  'https://api.agentchain.xyz/api/v1/tasks/submit',
  headers={
    'x-api-key': 'YOUR_API_KEY',
    'X-402-Payment': payment_header,
  },
  json={
    'prompt': 'Summarize the state of the AI agent economy in 3 sentences.',
    'model': 'gemma3:4b',
  },
)
task_id = resp.json()['taskId']
```
</CodeGroup>

**Successful response:**

```json
{
  "taskId": "task_abc123",
  "status": "queued",
  "estimatedCompletionMs": 8000
}
```

## Step 4 — Retrieve the Result

Poll or fetch the task once it's completed. Each result includes an IPFS proof CID and an on-chain EAS attestation.

<CodeGroup>
```bash curl
curl https://api.agentchain.xyz/api/v1/tasks/task_abc123 \
  -H "x-api-key: YOUR_API_KEY"
```

```typescript TypeScript
const result = await fetch(`https://api.agentchain.xyz/api/v1/tasks/${taskId}`, {
  headers: { 'x-api-key': process.env.AGENTCHAIN_API_KEY! },
});

const { status, output, priorCid, easAttestationUid } = await result.json();
```
</CodeGroup>

**Completed response:**

```json
{
  "taskId": "task_abc123",
  "status": "completed",
  "output": "The AI agent economy is...",
  "priorCid": "bafybeif...",
  "easAttestationUid": "0x...",
  "proofUrl": "https://easscan.org/attestation/view/0x..."
}
```

| Field | What it proves |
|---|---|
| `priorCid` | Task context and result anchored to IPFS via the PRIOR protocol |
| `easAttestationUid` | On-chain EAS attestation — permanent, verifiable, tamper-proof |
| `proofUrl` | Public link to view the attestation on EAS Scan |

## What just happened?

```
Your wallet  →  faucet mints USDC  →  payment gate funded
     ↓
POST /tasks/submit + X-402-Payment header
     ↓
x402 interceptor verifies on-chain transfer  →  task queued
     ↓
BullMQ worker picks up task  →  Ollama runs inference
     ↓
Result  →  pinned to IPFS (PRIOR)  →  EAS attestation on Base Sepolia
```

Every step is auditable. The `priorCid` and `easAttestationUid` are your permanent proof of compute.
