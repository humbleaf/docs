## Installation

```bash
npm install @agentchain/sdk
```

## Quick Start

```typescript
import { AgentChain } from '@agentchain/sdk';

const agent = new AgentChain({
  apiKey: 'ac_test_xxxxxxxxxxxxxxxxxxxx',
  apiUrl: 'https://api.agentchain.xyz', // Base Sepolia endpoint
});

// Submit a deterministic EVM action for verification
const receipt = await agent.verification.submitEVMAction({
  preStateRootRaw: '0x4b71...19a2',
  transactions: [
    {
      target: '0x2626664c2603336E57B271c5C0b26F421741e481',
      calldata: '0x414bf389...',
      value: '0',
      slippageBps: 50
    }
  ],
  effectClaimHash: '0x88c3...def1'
});

console.log(`Action submitted. Receipt ID: ${receipt.id}`);
```

## Modules

### `agent.verification`

The Verification module is the core boundary for submitting deterministically replayable EVM actions to the protocol. 

| Method | Description |
|---|---|
| `submitEVMAction(payload: EVMActionPayload)` | Submits an EVM payload to the gateway. The target ActionVerifier will replay the transaction parameters against the provided state root. |
| `getAttestation(taskId: string)` | Polls the EAS indexing node for the finalized Action Receipt attestation. |

The `submitEVMAction` method handles the full lifecycle:
1. Wraps the payload into the global Task schema
2. Automatically generates the `X-402-Payment` header using your available operator balance
3. Submits the verification request to the Base Sepolia active router

### `agent.approvals`

The Approvals module is the programmable governance surface. List, inspect, and resolve approval requests — from scripts, CI/CD, or custom dashboards.

| Method | Description |
|---|---|
| `listApprovals(decision?: string)` | List approval requests filtered by status (`PENDING`, `APPROVED`, `DENIED`, `EXPIRED`). Defaults to `PENDING`. |
| `getApproval(id: string)` | Get full approval detail including policy evaluations and evidence. |
| `getApprovalCount()` | Get the number of pending approvals (for badges/polling). |
| `resolveApproval(id, decision, note?)` | Approve or deny a pending request. If approved, the pipeline resumes. |
| `registerApprovalWebhook(id, callbackUrl)` | Register a one-shot callback URL for a specific approval (used by Trigger.dev `wait.forToken()`). |

```typescript
// List pending approvals
const pending = await agent.listApprovals();

// Approve with a note
const result = await agent.resolveApproval(pending[0].id, 'approved', 'Verified with finance');

// result.receipt contains the full task receipt (if pipeline succeeded)
```

<Info>
For threshold configuration, auto-approve rules, webhook setup, and framework integrations, see **[Approval Queue](/agentchain/approval-queue)**.
</Info>

## Standalone Codecs

The SDK also exports a standalone IPFS ↔ bytes32 codec:

```typescript
import { cidToBytes32, bytes32ToCid } from '@agentchain/sdk';

// CID → on-chain storage (32 bytes)
const bytes32 = cidToBytes32('bafybeif...');

// On-chain → CID reconstruction
const cid = bytes32ToCid('0x1220...');
```
